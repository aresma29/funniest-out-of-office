# The Funniest Out-of-Office

One out-of-office message, written by an inbox that has clearly had enough of the job.

> I'm out of office until Monday; my inbox has been promoted to acting manager and has already denied your request.

## How it works

`main.py` finds `entry.txt` next to itself (via `__file__`, so it works from any working directory), reads the single line, strips the trailing newline, and prints it to stdout. Standard library only, no arguments, exits 0.
